# SensLab for Windows

Public distribution repository for SensLab installers and signed automatic updates.

Download approved versions from [Releases](https://github.com/spawn1986/senslab-releases/releases).

This repository does not contain the application source code, signing keys or personal assessment data.

Repositorio de distribucion: instaladores y actualizaciones firmadas. El codigo fuente y los datos personales permanecen locales.
